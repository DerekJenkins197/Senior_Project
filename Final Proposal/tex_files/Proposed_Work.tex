


A project includes some things and excludes others you know you won't work on. 
Define more explicitly what is included and not included here. 
What will be demonstrated at project completion at Demo Day?

For our project, we will include parts of the gun that are necessary to demo the smart trigger functionality. 
Items Included:
\begin{itemize}
    \item Lower receiver: This is the part of the gun that contains the trigger mechanism and is necessary for demonstrating the smart trigger functionality.
    \item RFID reader: This is the component that will be used to authenticate the user and ensure that only authorized users can fire the gun.
    \item RFID tag: This is the component that will be attached to the user's ID and will be read by the RFID reader to authenticate the user.
    \item Microcontroller: This is the brain of the smart trigger system and will be responsible for processing the RFID data and controlling the trigger mechanism.
    \item Custom PCB: This will be used to connect all the components together and ensure that they work together seamlessly.
\end{itemize}
Items Excluded:
\begin{itemize}
    \item Upper receiver: This is the part of the gun that contains the barrel and is not necessary for demonstrating the smart trigger functionality.
    \item Stock: This is the part of the gun that provides support and is not necessary for demonstrating the smart trigger functionality.
    \item Grip: This is the part of the gun that is held by the user and is not necessary for demonstrating the smart trigger functionality.
\end{itemize}
