\begin{abstract}
This project proposes a smart trigger for firearms that uses RFID technology to authenticate the user and ensure that only authorized users can fire the gun. 
This would help to prevent accidental shootings and unauthorized use of firearms, ultimately improving public safety. This paper will discuss solutions already in the market,
the proposed solution, and the ethical considerations that need to be taken into account when designing and implementing such a system. It will also explore the project and outline
the tasks that need to be completed in order to successfully implement the smart trigger and demonstrate its functionality at Demo Day. The risks associated with the project will 
also be assessed and strategies for mitigating those risks will be discussed.

\end{abstract}
