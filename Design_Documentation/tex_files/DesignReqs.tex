The design has several requirements and constraints to meet. 
The priority and explanation is as follows:
\begin{enumerate}
    \item Widely and easily applicable
        \begin{itemize}
            \item The design is meant to work with any standard AR-15 and should be able to 
                  added in simply and easily. If it was a one off product the ultimate effect
                  would be far less.  
        \end{itemize}
    \item Battery operated
        \begin{itemize}
            \item This is a simple requirement but it means that the AR-15 can be away from
                  an outlet and be used at a gun range, hunting in remote areas, or in the field
                  by police officers.
        \end{itemize}
    \item Small
        \begin{itemize}
            \item Having a large cumbersome device added to a rifle such as the AR-15 
                  creates a big discouragement from use. Keeping the device small and out
                  of the way allows a user to basically hide that it even exits.
        \end{itemize}
    \item Reliable
        \begin{itemize}
            \item A tool that can only be used 50\% of the time is not a tool worth having.
                  In many applications an AR needs to be used at the drop of a hat and needs
                  to be relied on otherwise mortal consequences may ensue.
        \end{itemize}
    \item Quick
        \begin{itemize}
            \item The best example is an police officer needing their rifle while in a gun fight.
                  If the AR is not ready when the officer is it may as well not be there at all.
        \end{itemize}
\end{enumerate}
